# Laptop Data Analysis   
A comprehensive exploratory data analysis (EDA) project that examines laptop data to uncover insights into trends, pricing, specifications, and performance metrics.  

## Features  

### Dataset Overview  
- Contains information on laptop brands, models, specifications, prices, and ratings.  
- Includes categorical and numerical attributes like processor type, RAM, storage, screen size, and GPU.  

### Exploratory Data Analysis (EDA)  
- **Data Cleaning**:  
  - Handling missing values.  
  - Removing duplicates.  
  - Standardizing inconsistent formats.  
- **Data Visualization**:  
  - Distribution of laptop prices.  
  - Brand-wise sales comparison using bar charts.  
  - Correlation between specifications (e.g., RAM, processor type) and pricing using heatmaps.  
- **Insights and Trends**:  
  - Identifying popular laptop brands and models.  
  - Analyzing the impact of specifications (e.g., SSD vs. HDD storage) on performance metrics and pricing.  
  - Examining trends in screen sizes and their influence on user ratings.  

## Tools Used  
- **Python Libraries**:  
  - Pandas: For data manipulation and preprocessing.  
  - Matplotlib & Seaborn: For data visualization and chart creation.  
  - NumPy: For numerical computations and handling arrays.  

## Conclusion  
This project was a valuable learning experience in applying EDA techniques to real-world data. Through cleaning, preprocessing, and visualizing the laptop dataset, I gained insights into data manipulation, identifying trends, and uncovering actionable insights. Skills in using Python libraries such as Pandas, Matplotlib, and Seaborn were honed, helping me effectively analyze and interpret complex datasets. These skills can now be applied to various domains for informed decision-making and analytical exploration.
